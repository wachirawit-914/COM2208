# 1.ความหมายของเทคโนโลยี
เทคโนโลยี หมายถึง สิ่งที่มนุษย์พัฒนาขึ้น เพื่อช่วยในการทำงานหรือแก้ปัญหาต่าง ๆ เช่น อุปกรณ์, เครื่องมือ, เครื่องจักร, วัสดุ หรือ แม้กระทั่งที่ไม่ได้เป็นสิ่งของที่จับต้องได้ เช่น กระบวนการต่างๆ เทคโนโลยี เป็นการประยุกต์ นำเอาความรู้ทางวิทยาศาสตร์มาใช้ และก่อให้เกิดประโยชน์ ในทางปฏิบัติ แก่มวลมนุษย์
